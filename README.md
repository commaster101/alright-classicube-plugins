| Name |	Description |
| :--- | :--- |
| gunsV2 | Adds a "gun game" with 4 hit scan weapons, health and accurate collisions with partial blocks (unlike the built in gun command)|
| mcstairs | uses custom block hit-box trickery to make Minecraft style stairs instead of the quarter blocks commonly used in servers |
| signs | Allows the creation of small text in the world by defining a particle for every letter and dynamically loading the particles around the player. I suggest restricting the creation of these signs to high ranking players or admins for moderation and lag reasons |
| setglobalvisit | adds a command to change the global per-visit for every map, made this to fix players being unable to go to old maps when adding a rank below guest in mcgalaxy |
